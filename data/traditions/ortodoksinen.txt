# Arvio ortodoksisten (karjalaisten ja muiden ortodoksien) yleisimmistä
# etunimistä 1700–2026
#
# Tämä EI ole tilasto. Väestötiedoista ei saa nimiä uskontokunnan mukaan,
# joten listat on koottu käsin ja ne ovat arvioita. Lähteet:
#   - Outi Patronen: Raja-Karjalan ortodoksien nimenvalinta ja
#     ristimänimivalikoima 1890–1914. Virittäjä 1/2020, s. 84–101.
#     https://journal.fi/virittaja/article/view/64161
#     Taulukko 1: 12 yleisintä nimeä Ägläjärvellä (1913) ja Kaitajärvellä
#     (1910) kantajamäärineen. Jaksojen 1860–1899 ja 1900–1929 kärki
#     perustuu tähän (esim. Anna 40, Maria 36, Jevdokia 20; Ivan 38,
#     Vasili 24, Feodor 17).
#   - Denis Kuzmin: Old Karelian personal names. ESUKA – JEFUL 13–2 (2022),
#     s. 247–273. https://doi.org/10.12697/jeful.2022.13.2.08
#     Karjalaiset kansankieliset muodot (taulukko 2).
#   - Denis Kuzmin: Naisten nimet Karjalassa (esitelmä, Helsingin yliopisto).
#     https://blogs.helsinki.fi/personal-name-systems/files/2017/02/KuzminDenis_Naistennimet_Karjalassa.pdf
#     Vuoden 1650–51 karjalaisluettelon naisten nimet (Maria 127,
#     Fedosja 44, Fevronja 28 …); jaksojen 1700–1859 pohja.
#   - Pertti Lampi (toim.): Perinteisiä karjalaisia etunimiä. Karjalan
#     Kielen Seura 2009.
#   - Vuodesta 1930 alkaen yleistieto: suomalaistuminen sotien jälkeen ja
#     1990-luvulta venäjänkielisten maahanmuuttajien nimet.
#
# Karjalaisen muodon perässä suluissa on kirkonkirjoihin kirjattu
# kirkkoslaavilainen tai venäläinen muoto (Iivana → Ioann). Nimet, joille
# ei ole vakiintunutta suomalaista tai karjalaista muotoa, ovat kirjatussa
# muodossaan.
