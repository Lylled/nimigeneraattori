# Arvio vuosina 1700–1899 syntyneiden yleisimmistä etunimistä
#
# Tämä EI ole tilasto. Ennen vuotta 1900 syntyneistä ei ole kattavaa avointa
# nimitilastoa, joten listat on koottu käsin nimihistorian yleistiedon
# pohjalta ja tarkistettu suuntaa antavasti seuraavia vasten (ks.
# docs/data-sources.md):
#   - HisKi-otos: noin 2 300 vuoden 1890 alussa kastettua lasta, vain lapsen
#     ensimmäinen etunimi
#   - Tuomas Salsten julkaisemat vuosikymmenlistat 1860–1890-luvuilla
#     syntyneistä (kuolleiden luettelot 1955–1970 ja Kelan reikäkortit)
#   - Hellevi Arjava: Alpiini ja Otteljaana (SKS 2005) ja Eero Kiviniemi:
#     Rakkaan lapsen monet nimet (1982) nimien yleisistä suosionvaihteluista
#
# Muoto: [alkuvuosi-loppuvuosi sukupuoli], sen jälkeen nimet arvioidussa
# yleisyysjärjestyksessä yleisimmästä alkaen, yksi riviä kohti. Suluissa on
# tarvittaessa muoto, jolla nimi tavallisesti kirjattiin kirkonkirjoihin.
# Ne jäävät pois vuodesta 1860 alkaen, koska silloin ruotsalaiset muodot
# (Johan, Karl) olivat jo myös omia nimiään suomalaisten muotojen rinnalla.
#
# Ortodoksisen Karjalan nimistö (esim. Iivana, Vasili, Okahvia) ei vielä ole
# mukana.
